SPECTRAL SAFE

Privacy Policy

Last updated: November 4, 2026

1. About SPECTRAL SAFE

SPECTRAL SAFE is an independent cloud-backed game launcher under development. It is designed to access personally owned game files stored in user-authorized cloud storage services.

2. Google Drive Access

With your authorization, SPECTRAL SAFE may access Google Drive files and folders as permitted by the OAuth permissions you grant.

This access is intended for browsing game folders, discovering compatible game files, and reading game data required for local execution.

If optional cloud save synchronization is enabled, the application may also upload or update designated save files.

3. Data Stored Locally

SPECTRAL SAFE may store application settings, game library information, temporary game caches, diagnostic logs, and authentication information on your device.

Temporary game data may be removed according to storage settings. Save files should be maintained separately from disposable caches.

4. Use of Information

Google Drive data is intended to be used to provide the cloud game library, game discovery, game launching, and optional save synchronization features.

SPECTRAL SAFE is not intended to sell personal information or use Google Drive data for advertising.

5. Data Sharing

SPECTRAL SAFE is designed to process game files on the user's own device. Google Drive integration necessarily communicates with Google's services.

Any future third-party services or data-sharing practices will require appropriate disclosures in this policy.

6. Security

SPECTRAL SAFE aims to protect authentication credentials and avoid including sensitive tokens in public logs or repositories.

No software or network transmission method can guarantee absolute security.

7. Your Choices

You can revoke Google account access through your Google Account's third-party connection settings.

Local application data may be managed through SPECTRAL SAFE's available settings or operating system tools.

8. Google API Services

SPECTRAL SAFE's use of information received from Google APIs is intended to comply with the Google API Services User Data Policy , including applicable Limited Use requirements.

9. Policy Changes

This policy may be updated as SPECTRAL SAFE develops new features. Changes will be published on this page.
